# Security

Report security issues privately to **support@proximaforma.com**. Include the affected integration version, action and a minimal reproduction. Do not post OAuth tokens, sign-in codes, account credentials, private artwork or personal data in public issues.

This repository contains a hosted MCP configuration and design skill. OAuth authentication and authorization are handled by Claude and the Proxima Forma service. Revoke a connection from **Connect agent** in the Proxima Forma workspace if its access is no longer needed.
